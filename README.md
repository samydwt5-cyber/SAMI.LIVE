# SAMI LIFE | حياة سامي

PWA شخصي، يعمل بدون سيرفر أو قاعدة بيانات. بياناتك في localStorage على جهازك فقط.

## النشر
1. GitHub: أنشئ مستودعًا جديدًا (Public أو Private) وارفع **محتويات** هذا المجلد (index.html في الجذر).
2. Vercel: Add New → Project → اختر المستودع → Framework Preset: Other → Deploy (بدون Build Command).
3. افتح رابط Vercel (HTTPS) في Chrome على Android → القائمة ⋮ → «تثبيت التطبيق».

## تحديث لاحق
بعد أي تعديل على الملفات غيّر اسم الكاش `V` في `service-worker.js` (الإصدار الحالي: sami-life-v4) ليصل التحديث للهاتف.

## النسخ الاحتياطي
من الإعدادات → 💾 النسخ الاحتياطي، صدّر بياناتك (JSON) بشكل دوري. عند تغيير الجهاز أو مسح بيانات المتصفح، استورد الملف من نفس الشاشة.
